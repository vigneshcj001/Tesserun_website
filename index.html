What is Tesserun?+

Tesserun is an early native Rust desktop development studio. It connects your chosen AI model to a workflow for planning, generating source, reviewing, and publishing static websites.

How do I get started?+

Download the Windows executable and keep it in a writable folder. Open it, configure a provider and model in Settings, then describe your first project in Development. Model providers may charge for API usage.

Which platforms are available?+

The current downloadable build is for Windows x64. macOS and Linux downloads are not available. This is a portable executable, not an installer.

Can I use a local model?+

Yes. Connect to an installed model through a local Ollama endpoint. You can also use OpenAI, Anthropic, Gemini, or Groq with your own provider credentials.

Does Tesserun test my application?+

The current version performs deterministic static source checks and advisory AI review. It does not execute generated applications or verify their runtime behavior. Test your application before publishing.

Where are my projects stored?+

Projects are saved locally under .tesserun-rust in the working directory unless you configure a different data root. Saved source is unencrypted. Model requests send your brief and relevant source to your selected provider.
